# FlavorAI - Personal Recipe Discovery Platform (Frontend)

**EN**

## Project Description

FlavorAI is a web application that helps users discover, add, rate, and manage their personal recipes.
The project is built with Next.js 13, TypeScript, and Tailwind CSS.

## Core Functionality
- View all recipes
- Search recipes by name
- Add a new recipe (title, description, ingredients)
- Edit an existing recipe
- Delete a recipe
- Rate recipes (1-5 stars)
- View own recipes separately
- Local data storage using localStorage (backend simulation)

## Tech Stack
**Frontend:** Next.js 13 (App Router), React, TypeScript, Tailwind CSS
**Data Storage:** localStorage
**Icons:** react-icons

## How to run the project locally

1. Clone the repository:

  ```bash
  git clone <repository_URL>
  cd flavorai-frontend
  ```

2. Install dependencies:

  ```bash
  npm install
  ```

3. Start the development server:

  ```bash
  npm run dev
  ```

4. Open in your browser: 
  http://localhost:3000

## Опис проєкту

FlavorAI — це веб-додаток, що допомагає користувачам знаходити, додавати, оцінювати та керувати власними рецептами.  
Проєкт реалізовано за допомогою Next.js 13, TypeScript і Tailwind CSS.

## Основний функціонал

- Перегляд усіх рецептів
- Пошук рецептів за назвою
- Додавання нового рецепту (назва, опис, інгредієнти)
- Редагування існуючого рецепту
- Видалення рецепту
- Рейтинг рецептів (1-5 зірок)
- Перегляд власних рецептів окремо
- Локальне збереження даних у `localStorage` (імітація бекенду)

## Технічний стек

- **Frontend:** Next.js 13 (App Router), React, TypeScript, Tailwind CSS
- **Сховище даних:** localStorage
- **Іконки:** react-icons
