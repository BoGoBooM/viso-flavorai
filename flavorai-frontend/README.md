# FlavorAI - Personal Recipe Discovery Platform (Frontend)

## Опис проєкту

FlavorAI — це веб-додаток, що допомагає користувачам знаходити, додавати, оцінювати та керувати власними рецептами.  
Проєкт реалізовано за допомогою Next.js 13, TypeScript і Tailwind CSS.

## Основний функціонал

- Перегляд усіх рецептів
- Пошук рецептів за назвою
- Додавання нового рецепту (назва, опис, інгредієнти)
- Редагування існуючого рецепту
- Видалення рецепту
- Рейтинг рецептів (1-5 зірок)
- Перегляд власних рецептів окремо
- Локальне збереження даних у `localStorage` (імітація бекенду)

## Технічний стек

- **Frontend:** Next.js 13 (App Router), React, TypeScript, Tailwind CSS
- **Сховище даних:** localStorage
- **Іконки:** react-icons

## Як запустити проєкт локально

1. Клонуйте репозиторій:

   ```bash
   git clone <URL_репозиторію>
   cd flavorai-frontend
   ```

2. Встановіть залежності:

  ```bash
  npm install
  ```

3.	Запустіть проект у режимі розробки:

  ```bash
  npm run dev
  ```

4.	Відкрийте у браузері:
  http://localhost:3000
